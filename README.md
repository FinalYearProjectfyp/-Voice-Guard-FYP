# Voice-Guard-FYP
**Group Members:** Ummamah Aiman, Bisma Rizwan, Warda Zaheer 
**Supervisor:** Sir Muhammad Fahad

A machine learning–based security system that analyzes real-time or recorded audio to detect AI-generated/cloned voices, aimed at preventing voice-cloning fraud (e.g., fake emergency calls, impersonation scams). Combines audio feature extraction and deep learning classification to distinguish authentic human speech from synthetic/cloned audio.
